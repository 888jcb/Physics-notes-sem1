# Wave function

A generally complex probability amplitude used to describe a quantum state. Its squared magnitude gives probability density.

**Concrete example:** For a normalized one-dimensional state, integrating absolute psi squared over a region gives the probability of finding the particle there.

**Keep the distinction:** Psi itself is not a probability or a literal spread-out classical substance.
