# Interplanar spacing

The perpendicular separation between successive parallel planes in a specified crystal-plane family. For cubic geometry, d_hkl = a/sqrt(h squared + k squared + l squared).

**Concrete example:** The (110) cubic spacing is a/sqrt(2).

**Keep the distinction:** Use a perpendicular separation, not an arbitrary sloping distance between atoms.
