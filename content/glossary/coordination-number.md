# Coordination number

The number of nearest neighbours of a selected atom in a structure. It describes the atom's local surroundings.

**Concrete example:** For monatomic SC, BCC and FCC structures the values are 6, 8 and 12 respectively.

**Keep the distinction:** It is not atoms per unit cell, whose corresponding values are 1, 2 and 4.
