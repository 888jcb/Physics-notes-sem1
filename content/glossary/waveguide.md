# Waveguide

A structure whose boundaries and material properties keep waves concentrated near a path while allowing propagation along it.

**Concrete example:** An optical fibre guides electromagnetic waves; a microwave guide uses a different geometry and guiding mechanism.

**Keep the distinction:** Guiding is a wave phenomenon. Bouncing rays are a useful approximation for some fibres.
