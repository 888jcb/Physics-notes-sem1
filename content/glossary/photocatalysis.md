# Photocatalysis

Acceleration of a chemical reaction using a catalyst activated by light. Suitable absorbed photons create carriers that participate in surface reactions.

**Concrete example:** An appropriate semiconductor photocatalyst can help break down selected pollutants under suitable illumination.

**Keep the distinction:** It is not the same as merely filtering particles, and it is not guaranteed for every pollutant or nanomaterial.
