# Boundary conditions

Requirements a solution must satisfy at edges or interfaces. They select which wave patterns are physically allowed.

**Concrete example:** A wave function in an ideal infinite well vanishes at its walls, allowing only particular standing-wave patterns.

**Keep the distinction:** Real finite barriers can allow penetration; an infinite wall is an idealized model.
