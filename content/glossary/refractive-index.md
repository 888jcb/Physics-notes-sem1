# Refractive index

A number comparing the speed of light in vacuum with its phase speed in a material: n = c/v. A larger index means a lower phase speed at that wavelength. The index can depend on wavelength.

**Concrete example:** If n = 1.5, the phase speed is c/1.5, about 200 million metres per second.

**Keep the distinction:** A larger optical index does not necessarily mean a larger mass density.
