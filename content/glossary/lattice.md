# Lattice

An ideal periodic array of equivalent geometrical points. Every lattice point has the same environment when the array is extended.

**Concrete example:** A repeating grid is a simple two-dimensional picture of a lattice.

**Keep the distinction:** Lattice points are geometrical labels; an actual crystal also needs a basis of atoms.
