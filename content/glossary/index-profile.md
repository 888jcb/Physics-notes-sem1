# Index profile

How refractive index varies across a fibre's cross-section. A step profile changes abruptly at the core boundary; a graded profile changes gradually within the core.

**Concrete example:** In a graded-index core, outer regions can have a smaller index and higher phase speed than central regions.

**Keep the distinction:** Index profile and number of guided modes are two separate classifications.
