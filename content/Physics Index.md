## How to use the notes

1. Read one topic with its diagram, then explain it aloud without looking.
2. Reproduce the core diagram and formula from memory; label symbols and assumptions.
3. Cover the worked solution and solve the example yourself. Compare the **method**, not just the final number.
4. Answer the independent questions before opening the answer callout.
5. End the session with active recall. Revisit missed items after one day, three days and a week.

Recommended conceptual order: Module 1 → Module 2 crystal sections → Module 3 quantum foundations → Module 2 semiconductor sections → Module 3 statistics → Module 4. Reading modules in numerical order also works: each includes prerequisite explanations.
